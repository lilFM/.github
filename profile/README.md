## li’l Fan-made

**lilFM** *(short for “li’l Fan-Made”)* – a GitHub organization not only to keep personal repositories clean from the commercial media, but also to provide space for other fans to share their creativity with the world!

## Licenses

Each repository in this organization is created solely for entertainment, educational, and research purposes.

Because repositories may often use already licensed content, or repositories may use titles or references to already licensed media, the use of our code for any commercial purpose is strictly prohibited.

We are aware that code can be used for unscrupulous purposes (particularly scamming and fraud), so we try to choose licenses that prohibit commercial use and strictly require public availability of source code for projects derived from our source code.

### Open source

Our projects cannot be called purely open-source because the licenses restrict commercial use. It’s more correct to call our projects [“source-available”](https://en.wikipedia.org/wiki/Source-available_software).
